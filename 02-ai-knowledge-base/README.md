# AI-Assisted Academic Knowledge Base

A structured, traceable and continuously maintained
knowledge base for the academic and research profile
of Pravinkumar Ramchandra Ghodake.

## Purpose

To preserve original source datasets, reconcile records
from multiple independent sources, and maintain a
machine-readable academic knowledge base.

## Structure

- `source-exports/` — Original AI-generated datasets.
- `reconciliation/` — Comparisons, conflicts and verification.
- `canonical-database/` — Reconciled structured database.
- `PROFILE_KNOWLEDGE_BRIEF.md` — Human-readable profile.
- `MANIFEST.md` — Dataset provenance and version history.

## Evidence and Provenance

Original source files are preserved separately.
AI-generated statements are not automatically verified facts.
Disagreements and unresolved claims must remain documented.

The canonical database will be populated only after
source reconciliation is completed.

## Maintenance

New information should be added with its source,
date, verification status and change history.
